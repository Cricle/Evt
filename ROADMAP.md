# Roadmap

## Current focus

- Keep the Rust backend as the single server implementation.
- Preserve web and Tauri compatibility against the existing HTTP API contract.
- Continue improving SQL efficiency, compatibility coverage, and deployment ergonomics.

## Near-term work

- Expand integration and regression coverage around legacy-compatible endpoints.
- Improve deployment templates for self-hosted installations.
- Tighten observability, operational documentation, and release automation.
